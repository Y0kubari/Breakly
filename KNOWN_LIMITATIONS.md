# Известные ограничения

- Это первая нативная версия 0.1.0. Ручная матрица на разных видеодрайверах, нескольких мониторах, 125/150/200% DPI, Narrator, реальном сне, блокировке, перезапуске Explorer и «Не беспокоить» ещё требует выполнения. Реализованный путь не равен подтверждённому ручному тесту.
- Собственное окно видно на обычном рабочем столе. UAC, защищённый рабочий стол и эксклюзивный fullscreen игр не обходятся. Обычная доставка Windows реализована через Shell balloon, а не через WinRT Toast; она зависит от Windows и может подавляться.
- Отсутствие ввода не доказывает отсутствие зрительной нагрузки. Ввод — оценка участков с событиями за последние 15 секунд; экранное время — предполагаемое. Чтение и видео включаются вручную.
- При завершении процесса интервалы напоминаний начинаются заново. Активный отдых, откладывание и временная пауза не восстанавливаются после перезагрузки; настройки и уже сохранённая статистика сохраняются. При аварийном завершении возможна потеря до пяти минут новых агрегатов.
- Учет и обнаружение возврата к активности имеют дискретность до 15 секунд. Напоминания, сон/блокировка и календарная граница могут обрабатываться с задержкой очереди сообщений. Длительности считаются по монотонным часам, а не по количеству тиков. Отрезок, пересекающий дату, относится к предыдущему дню (обычно до 15 секунд; при открытом окне — до секунды).
- Окончание активного отдыха требует явного подтверждения; до подтверждения новые категории не показываются. Приложение не определяет объективное выполнение упражнений.
- Windows может кэшировать библиотеки и страницы памяти после закрытия интерфейса. Освобождение HWND/COM не означает немедленного возврата всех Private Bytes. Принудительное обрезание Working Set не применяется.
- Mica используется в верхней полосе главного окна; остальная поверхность непрозрачна ради совместимости с нативными доступными контролами. На Windows 11 до сборки 22621 используется обычный фон. Движущихся элементов и собственного анимационного движка нет, появление оформляет DWM.
- Все пользовательские кнопки/поля — стандартные Win32-контролы с отрисовкой в теме приложения. Полное тестирование Narrator и высокой контрастности не проведено. Русский — единственный язык; переключателя на другие локализации нет.
- Статистика хранится дневными агрегатами в одном JSON без базы данных. Файл ограничен 1 МиБ при чтении, что достаточно для многих лет обычных дневных записей; произвольные будущие схемы данных не принимаются автоматически.
- Цифровая подпись и установщик не созданы. При переносе EXE нужно обновить автозапуск. SmartScreen может проверить неподписанный EXE при скачивании.
