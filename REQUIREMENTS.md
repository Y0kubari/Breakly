# Пересмотр технического задания

Новые требования пользователя от 15 ноября 2026 имеют приоритет над исходным ТЗ. Продуктовые функции сохранены, технологические решения заменены.

## Обязательный стек и границы

C++20, Win32, Direct2D, DirectWrite, DWM, Windows SDK, CMake и MSVC x64. Нативный Shell_NotifyIcon. Настройки и дневные агрегаты статистики — компактный JSON. Runtime MSVC включён статически. Нет Electron, WebView2, WPF, WinUI 3, .NET Runtime, Chromium, SQLite, внешнего UI-фреймворка, службы, телеметрии, сети и облака.

## Функции

| Требование | Реализация |
|---|---|
| Глаза / разминка / перерыв | Независимые интервалы 20/45/60 мин, отдых 20/90/300 с, настройка всех значений |
| Приоритет и объединение | Перерыв → разминка → глаза; один слот предложения; сброс по достаточной длительности отдыха |
| Активность | GetLastInputInfo, режим чтения и видео, раздельные агрегаты ввода/экрана/подтверждения |
| Системные события | WTS lock/unlock, питание, дисплей, изменение времени, темы и Explorer |
| Собственные уведомления | Topmost, без первоначальной активации; действия и таймер, выбранный монитор |
| Обычные уведомления Windows | Shell balloon; переход к интерактивным действиям по нажатию; ограничения доставки Windows |
| Режимы | Мягкий с исчезновением, стандартный, настойчивый с повтором; все закрываются |
| Полный экран | Всегда / откладывать на минуту / ждать выхода; по умолчанию откладывание |
| Трей | Обзор, остаток времени, немедленный отдых, пауза 15/30/60, возобновление, настройки, выход |
| Автозапуск | Только после согласия, HKCU Run, без администратора, запуск в трей |
| Один экземпляр | Именованный mutex, SID, профиль, сеанс; IPC открытия существующего окна |
| Настройки | Все разделы исходного ТЗ; единственный язык — русский |
| Расписание | Дни, рабочие часы, тихие часы, переход через полночь, временная пауза |
| Статистика | Ввод как оценка, экран, предложено/начато/подтверждено/пропущено/отложено, самая длинная сессия; день и 7 дней |
| Сохранение | Атомарный JSON, копия повреждённого файла, пятиминутные контрольные записи |
| Стиль Windows 11 | Системный заголовок, DWM-скругления, Mica в верхней полосе, системная тема и акцент, Segoe UI Variable/Segoe UI |
| Доступность | Стандартные Win32-контролы с доступными именами и состояниями, Tab/Space, отдельное открытие уведомления для клавиатуры |
| DPI и мониторы | Манифест PerMonitorV2, WM_DPICHANGED, рабочая область монитора; вертикальная прокрутка настроек |

## Цели Release x64

Основной EXE до 5 МБ, предельная цель 10 МБ; фоновые Private Working Set желательно до 15 МБ, допустимо до 25 МБ; средний CPU менее 0,1%; трей менее секунды. Эти значения проверяются измерениями, а не объявляются гарантиями на любом оборудовании. Метрики всех этапов, методика и воспроизводимый сценарий — в PERFORMANCE.md.

## Готовность и оставшаяся проверка

Автоматические тесты ядра и проверки на доступном рабочем столе записаны в TEST_PLAN.md. Физические переключения сна, блокировки, «Не беспокоить», Explorer, нескольких мониторов и разных DPI требуют ручного теста; их прохождение не заявляется. Ограничения поставки перечислены в KNOWN_LIMITATIONS.md.
