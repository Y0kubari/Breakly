# Проверки Breakly

## Автоматические проверки

`tests/core_tests.cpp`: детерминированные часы, пороги 20/45/60 минут, приоритеты, один слот уведомления, пауза, откладывание, отсечение бездействия, чтение/видео без двойного учета, сон/блокировка, достаточный отдых, невозможность раннего/повторного подтверждения, независимость короткого и длинного отдыха, пропуск, смена даты/часов, ночное расписание, неделя через границу месяца, JSON и его повреждение, атомарное сохранение и чтение, отказ от неверных настроек. Проверяется также исключение сна по unbiased clock без события питания.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\desktop-smoke.ps1
```

Сценарий рабочего стола создаёт отдельный профиль, проверяет mutex/повторный запуск, создание и уничтожение главного HWND, уведомление и его кнопки, пятисекундный тестовый отдых и сохранение подтверждения, запись темы, штатный выход. Также проверяются Tab между действиями, сохранение фокуса при начале отдыха, пауза активного отдыха, черновик полей при событиях темы/DPI и прокрутка к полям и сохранению в окне 600×360. Синтетические WTS/Power/DPI-сообщения проверяют только обработчики; они не блокируют и не усыпляют компьютер, не меняют фактический DPI монитора. Снимки сохраняются из собственного окна, при перекрытии используется PrintWindow. Тестовые данные не удаляются автоматически.

Фактически выполнено: 49 проверок ядра в Release и Debug; 22 проверки рабочего стола в `checks/desktop-20261115-153012/passed.txt`; стресс-тест 200 циклов в `measurements/software-renderer`. Независимое ревью подтвердило закрытие четырёх замечаний к клавиатуре, сохранению черновика, прокрутке и активному отдыху. Это не заменяет ручную матрицу ниже.
