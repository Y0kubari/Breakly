# Breakly для Windows 11

Компактная утилита в трее: отдых для глаз, разминка и полноценный перерыв. C++20, Win32, Direct2D/DirectWrite. Без .NET, браузера, установки дополнительных библиотек и сети.

## Запуск

Откройте `dist\Breakly.exe`. Первая ручная загрузка открывает обзор с предложением автозапуска. Автозапуск включается только кнопкой «Включить автозапуск» либо в разделе «Общие». При входе в Windows используется `--background`, главное окно не открывается.

Основная поставка — один `Breakly.exe`. Сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1`. Требования к инструментам описаны в [BUILD.md](BUILD.md).

## Использование

- Значок в трее: щелчок открывает обзор, правый щелчок — меню паузы, перерыва, настроек и выхода.
- Закрытие главного окна уничтожает окно и его визуальные ресурсы; процесс остаётся в трее.
- «Выход» в меню значка полностью завершает процесс и сохраняет статистику.
- «Перерывы»: интервалы в минутах, длительности отдыха в секундах. По умолчанию 20/45/60 минут и 20/90/300 секунд.
- «Уведомления»: мягкое, стандартное или настойчивое напоминание; монитор; полноэкранные приложения; собственное окно либо уведомление Windows.
- «Активность»: пороги бездействия, режимы чтения и видео, использование сна и блокировки как возможного отдыха.
- «Расписание»: рабочие часы и дни, тихие часы; время вводится как `09:00`. Пауза на 15/30/60 минут доступна в трее.
- «Статистика»: сегодняшний день и последние семь календарных дней.

Собственное окно не использует доставку Windows Toast и поэтому не зависит от фильтра «Не беспокоить» в обычном сеансе. Оно не перехватывает фокус при появлении. Для клавиатуры откройте обзор и нажмите «Открыть напоминание». На защищённом рабочем столе, экране блокировки и поверх эксклюзивного полноэкранного режима показ не гарантируется. Системные уведомления могут подавляться Windows.

Кнопки позволяют начать отдых, отложить на пять минут или пропустить. После окончания таймера пользователь подтверждает отдых. Такое подтверждение не является объективным измерением отдыха. Закрытие активного таймера считается пропуском; закрытие предложения откладывает его на установленный интервал повтора.

## Данные и удаление

`%LOCALAPPDATA%\Breakly\settings.json` — настройки; `statistics.json` — дневная статистика. Атомарная запись через временный файл. Повреждённый файл сохраняется как `.damaged-…`, приложение использует безопасные значения по умолчанию. Статистика сохраняется при штатном выходе, уходе в сон и не чаще раза в пять минут при изменениях.

Для удаления выключите автозапуск, завершите Breakly через трей и удалите папку с программой. Папку данных можно сохранить либо удалить отдельно. Приложение не устанавливает службы, драйверы или задания планировщика.

## Проверки

`scripts\desktop-smoke.ps1` проверяет отдельный профиль: одиночный экземпляр, окна, подтверждение отдыха, сохранение настроек и статистики. `scripts\measure-performance.ps1` измеряет Release на Windows 11. Эти сценарии не включают автозапуск и не меняют пользовательский профиль Breakly.

Измерения и ограничения: [PERFORMANCE.md](PERFORMANCE.md), [TEST_PLAN.md](TEST_PLAN.md), [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md). Тестовые профили и снимки находятся в `checks`, отчёты — в `measurements`.
